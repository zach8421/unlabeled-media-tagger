# GPU pins — Linux / NVIDIA TITAN Xp (Pascal, compute capability 6.1)
#
# Apply ON TOP OF requirements.txt after the normal install:
#   ./.venv/bin/pip install -r requirements.txt
#   ./.venv/bin/pip install -r requirements-gpu.txt
#
# Why these exact versions (see dev-log/2026-06-11-gpu-enablement.md):
#   - tensorflow[and-cuda] floats the CUDA stack UP past TF's tested build.
#     On TF 2.21 that pulled CUDA 12.9 / cuDNN 9.23, which hits a TF 2.21
#     dlopen regression AND drops Pascal/6.1 from cuDNN's support matrix.
#   - Fix: TF 2.20.0 + CUDA 12.5 / cuDNN 9.3. cuDNN 9.3 still supports
#     Pascal and needs only driver >=525.60.13 (box has 535.309.01).
#   - Verified: both TITAN Xp register, a GPU matmul runs, and deepface
#     (retinaface + ArcFace) detection runs on GPU (~93% util, ~3.2 GiB).
#
# Do NOT install `tensorflow[and-cuda]` — the `and-cuda` extra will float
# these nvidia-*-cu12 wheels back up and break Pascal again. Pin instead.
